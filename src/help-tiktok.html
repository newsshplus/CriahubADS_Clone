Como Conectar o TikTok ao CriaHub

Guia completo para ligar a tua conta TikTok Business ao CriaHub e automatizar a tua presença na plataforma.

1. O que precisas

Antes de iniciar a conexão, garante que tens os seguintes elementos preparados:

Conta TikTok Business

A CriaHub apenas funciona com contas TikTok Business ou TikTok Ads Manager. Contas pessoais padrão não são suportadas porque não têm acesso à API de developer.

💡 Como mudar para conta Business: Abre o TikTok → Perfil → Menu (☰) → Definições e privacidade → Conta → Mudar para Conta Business. Seleciona a tua categoria (ex.: Tecnologia / Software) e confirma. A mudança é gratuita e não afeta o teu conteúdo existente.

Token de Acesso (Access Token)

O Access Token é uma chave de autenticação que permite ao CriaHub aceder à tua conta TikTok de forma segura via API. Expire normalmente entre 24h e 365d consoante o tipo — o CriaHub suporta renovação automática.

2. Como obter o TikTok Access Token

Segue estes 6 passos para gerir o teu token de acesso. Todo o processo demora cerca de 10-15 minutos.

1

Criar conta no TikTok for Business

Acede a business.tiktok.com e cria uma conta Business. Utiliza o mesmo email associado ao teu perfil TikTok. Preenche os dados da empresa (podes usar "Empresário Individual" se fores freelancer).

2

Aceder ao Developer Portal

Navega até developers.tiktok.com e faz login com as credenciais da tua conta TikTok Business. Aceita os termos e condições do programador TikTok se for a primeira vez.

3

Criar uma aplicação

No painel do Developer Portal, clica em "Create App" e preenche:

  • App Name: CriaHub
  • Description: Instagram and TikTok automation platform for business
  • Platform: Web
  • Redirect URI: https://criahub.global/auth/tiktok/callback
4

Solicitar permissões

No separador "Permissions", solicita as seguintes permissões:

PermissãoDescrição
user.info.basicObter dados básicos do perfil (nome, foto, seguidores)
video.listListar e aceder aos vídeos publicados
comment.readLer comentários nos teus vídeos
message.sendEnviar mensagens diretas (DMs)
5

Gerar Access Token via OAuth

No separador "Authentication", clica em "Generate Token". Serás redirecionado para o TikTok para autorizar a aplicação. Confirma as permissões e autoriza o acesso.

⚠️ Nota importante: O token de curto prazo (Short-Lived) expira em 24 horas. Para automação contínua, gera um Long-Lived Token (válido até 365 dias) na secção "Token Management".
6

Copiar o token e colar no CriaHub

Copia o Access Token gerado. No painel do CriaHub, navega até Configurações → TikTok, clica em "Adicionar Conta" e cola o token no campo indicado. Clica em "Guardar e Testar Conexão".

✓️ Verificação: Se o token for válido, verás um ✔ verde com o nome da tua conta TikTok. Se receberes um erro, consulta a secção de Troubleshooting abaixo.

3. Conexão automática via navegador (semi-automática)

Se preferes não gerir tokens manualmente, o CriaHub oferece um método alternativo via extensão de navegador.

Instalar extensão CriaHub Connector

Instala a extensão oficial CriaHub Connector na Chrome Web Store.

  • 🔗 Instalar CriaHub Connector (Chrome Web Store)
  • Após instalar, o ícone do CriaHub aparecerá na barra de extensões do Chrome

Abrir TikTok no navegador

Inicia sessão na tua conta TikTok Business no navegador onde a extensão está instalada. Navega pelo menos uma vez pela tua perfil para garantir que a sessão está ativa.

A extensão captura a sessão automaticamente

Quando o TikTok estiver aberto, a extensão CriaHub Connector deteta a sessão ativa e captura os dados de autenticação de forma segura. Nada é enviado sem a tua autorização — verás um popup de confirmação.

CriaHub sincroniza os dados via polling

Após a autorização, o CriaHub sincroniza periodicamente (polling a cada 5 minutos) os dados da tua conta TikTok: comentários, mensagens, métricas de vídeos e dados de perfil.

⚠️ Nota sobre Browser Connector: O método via navegador é mais lento do que a API direta e depende do navegador estar aberto. Para automação 24/7, recomendamos o método via Access Token descrito na secção anterior.

4. Funcionalidades disponíveis

Com o TikTok conectado ao CriaHub, tens acesso às seguintes funcionalidades:

💬 Resposta automática a comentários em vídeos

Configura respostas automáticas personalizadas para comentários nos teus vídeos. Define palavras-chave e templates de resposta para interagir com a tua audiência em tempo real, mesmo quando não estás online.

📩 Envio de DMs quando alguém comenta com palavra-chave

Automatiza o envio de mensagens diretas quando um utilizador comenta com uma palavra-chave específica. Por exemplo, se alguém comenta "INFO", o CriaHub envia automaticamente uma DM com o link ou catálogo que configuraste.

📈 Métricas de engajamento

Acede a métricas detalhadas de engajamento: taxa de resposta a comentários, tempo médio de resposta, comentários mais populares, e evolução do engajamento ao longo do tempo.

📊 Analytics de campanhas TikTok Ads

Se tiveres uma conta TikTok Ads Manager conectada, o CriaHub sincroniza os dados das tuas campanhas publicitarias: impressões, cliques, CTR, CPC, conversões e ROI — tudo num painel unificado.

5. Limitações atuais

⚠️ Importante — Lê antes de utilizares: O TikTok tem restrições de API diferentes do Instagram. Estas são as principais limitações que precisas de conhecer.

TikTok não tem API oficial para DMs

Ao contrário do Instagram (que tem a Messenger API), o TikTok não oferece uma API oficial de envio de DMs para terceiros. Isto significa que o envio de mensagens diretas não pode ser feito 100% via API.

DMs são enviadas via Browser Connector ou redirecionamento

As DMs no TikTok são processadas através do CriaHub Browser Connector (extensão de navegador descrita na secção 3) ou via redirecionamento para link — por exemplo, gerar um link que abre o chat do TikTok com uma mensagem pré-preenchida.

Taxa de envio: máx. 50 DMs/hora

O TikTok impõe um limite de 50 mensagens diretas por hora por conta. O CriaHub respeita este limite automaticamente e distribui os envios ao longo do tempo para evitar bloqueios. Se atingires o limite, as mensagens em fila de espera são enviadas automaticamente quando a janela se renova.

6. Troubleshooting

🔴 "Token expirado"

Causa: O Access Token de curto prazo expirou (24h) ou o token longo atingiu o limite de 365 dias.

Solução: Acede ao TikTok Developer Portal → "Token Management" → "Regenerate Token". Copia o novo token e atualiza-o no CriaHub em Configurações → TikTok.

🔴 "Conta não é Business"

Causa: A conta TikTok associada ao token é uma conta pessoal padrão, não Business.

Solução: No TikTok, vai a Perfil → Menu → Definições e privacidade → Conta → Mudar para Conta Business. Após a mudança, regenera o token no Developer Portal e volta a inseri-lo no CriaHub.

🔴 "Mensagens não enviadas"

Causa: Provável atingimento do rate limit de 50 DMs/hora ou bloqueio temporário do TikTok devido a atividade suspeita.

Solução: Verifica no painel do CriaHub (Dashboard → TikTok → Status) se o rate limit está ativo. Se sim, aguarda a renovação da janela horária. Se o problema persistir, verifica se a extensão Browser Connector está ativa e se o TikTok está aberto no navegador.

🔴 "Extensão não deteta sessão"

Causa: O TikTok não está aberto no navegador ou a sessão expirou.

Solução: Fecha e volta a abrir o TikTok no Chrome. Garante que estás autenticado. Clica no ícone da extensão CriaHub Connector e seleciona "Atualizar sessão".
